# Fünf formatnahe Reel-Skripte mit Kommentar-CTA

Stand: 6. September 2026

Diese Fassungen behalten Grundidee, Beat-Reihenfolge, Listenlänge und Tempo der erfolgreichen Beleg-Reels. Wortlaut, Beispiele und Positionierung sind eigenständig. Jedes Reel endet mit einem klaren Kommentar-CTA.

## CTA-Pakete

| Keyword | Versprochenes Material |
| --- | --- |
| `FINANZ` | Offizielles Anthropic-Repository, Übersicht der zehn Agentenvorlagen und deutsche Setup-Checkliste |
| `TIER` | KI-Projekt-Tier-Liste plus Bewertungsschema |
| `SYSTEM` | Offizieller Hermes-Agent-Repo-Link, geprüfter Neun-Schritte-Plan und Wochenend-Checkliste |
| `SIGNAL` | Signal-Room-Workflow als Schritt-für-Schritt-Plan |
| `TEAM` | Offizieller Codex-Plugin-Repo-Link, Installationsanleitung und Build-und-Review-Ablauf |

Die fünf Pakete müssen vor der Veröffentlichung fertig sein. Der CTA verspricht eine konkrete Zusendung.

## Quellen-Grenze für den CTA

Ein Reel mit Repository-, Plugin- oder Tool-Bezug wird vor der Aufnahme gegen die Primärquelle geprüft. Der CTA muss genau benennen, was verschickt wird.

| Reel | Quellenstatus | Grenze |
| --- | --- | --- |
| `FINANZ` | [Anthropic-Ankündigung](https://www.anthropic.com/news/finance-agents) und offizielles Repository [`anthropics/financial-services`](https://github.com/anthropics/financial-services) geprüft | Repo-Link, Übersicht und eigene deutsche Checkliste versenden. Keine frei erfundenen Agentenrollen. |
| `TIER` | Kein Repository als Grundlage identifiziert | Eigenes Bewertungsschema versenden. Keine fremde Setup-Anleitung versprechen. |
| `SYSTEM` | Offizielles Repository [`NousResearch/hermes-agent`](https://github.com/NousResearch/hermes-agent) geprüft | Repo-Link, geprüften Neun-Schritte-Plan und Sicherheitscheckliste versenden. Claude Design nur als eigene Integration kennzeichnen. |
| `SIGNAL` | Eigener Signal-Room-Workflow | Einen Ablaufplan versenden. Das private Repository bleibt privat. |
| `TEAM` | Offizielles Repository [`openai/codex-plugin-cc`](https://github.com/openai/codex-plugin-cc) geprüft | Codex-Plugin und konkreten Build-und-Review-Ablauf erklären. Nicht behaupten, alle ChatGPT-Modelle würden automatisch in Claude arbeiten. |

## Reel 1: Drei KI-Agenten für deine Finanzsteuerung

**Beleg-Reel:** [Drei Finanz-Agenten](https://www.instagram.com/p/DbeDeiOSnu-/), 846.340 Plays, 23,90x Outlier

**Hook im Bild:** ANTHROPIC HAT 10 FINANZ-AGENTEN VERÖFFENTLICHT

**Sprechdauer:** etwa 52 bis 59 Sekunden

**Skript**

Anthropic hat zehn fertige Agentenvorlagen für Finanzteams veröffentlicht. Drei davon zeigen besonders gut, wie spezialisierte KI-Rollen arbeiten.

Der Market Researcher erstellt zu einem Sektor eine Marktübersicht, eine Wettbewerbsanalyse, Vergleichskennzahlen und eine Liste möglicher Investmentideen.

Der Model Builder baut DCF-, LBO- und Vergleichsmodelle direkt in Excel. Er erstellt auch integrierte Modelle aus GuV, Bilanz und Cashflow.

Der Earnings Reviewer liest den vollständigen Earnings Call und die veröffentlichten Berichte. Danach aktualisiert er das Modell und erstellt einen Entwurf für die Ergebnisanalyse.

Im Repository stecken Agentenvorlagen, Skills und Daten-Connectoren. Einige Connectoren setzen eigene Abonnements oder API-Zugänge voraus. Alle Ergebnisse bleiben Entwürfe, bis ein qualifizierter Mensch sie geprüft hat.

Wenn du das offizielle Repository, die Übersicht aller zehn Agentenvorlagen und meine deutsche Setup-Checkliste haben willst, kommentiere FINANZ und ich schicke sie dir zu.

**Aufnahme:** Den Hook in einem Take sprechen. Vor jedem Agenten kurz pausieren. Beim CTA das Keyword langsamer und deutlich aussprechen.

## Reel 2: KI-Projekte im Tier-Ranking

**Beleg-Reel:** [Die besten AI Tools 2026](https://www.instagram.com/p/DcgYou7jHu1/), 605.332 Plays, 21,68x Outlier

**Hook im Bild:** ICH RANKE KI-PROJEKTE VON D BIS S

**Sprechdauer:** etwa 39 bis 45 Sekunden

**Skript**

Ich ranke die wichtigsten KI-Bausteine für den Mittelstand von D bis S.

Ein einzelner Chatbot ohne Firmendaten landet bei mir im D-Tier. Er beantwortet Fragen, kennt deinen Betrieb aber nicht.

Prompt-Sammlungen kommen ins C-Tier. Sie helfen bei einzelnen Aufgaben, doch jeder startet immer wieder von vorn.

Ein Copilot mit festen Vorlagen und Zugriff auf Dokumente kommt ins B-Tier.

Ein Workflow mit Datenzugriff und menschlicher Freigabe gehört ins A-Tier.

S-Tier ist ein KI-Betriebssystem mit verbundenen Workflows, gemeinsamem Gedächtnis, klaren Rollen und Messwerten.

Wenn du meine komplette Tier-Liste inklusive Bewertungsschema haben willst, kommentiere TIER und ich schicke sie dir zu.

**Aufnahme:** Nach jeder Tier-Stufe eine kurze Pause lassen. Die Stufen werden später als Karten über dem Talking Head eingeblendet.

## Reel 3: Hermes Agent in neun Schritten

**Beleg-Reel:** [Eigener Jarvis an einem Wochenende](https://www.instagram.com/p/Dc4WnCDtbsm/), 345.117 Plays, 9,74x Outlier

**Hook im Bild:** DEIN EIGENER KI-AGENT AN EINEM WOCHENENDE

**Sprechdauer:** etwa 66 bis 75 Sekunden

**Skript**

So baust du an einem Wochenende die erste Version deines eigenen KI-Agenten in neun Schritten.

Schritt eins: Wähle einen Rechner oder Server, auf dem dein Agent laufen soll.

Schritt zwei: Installiere Hermes Agent aus dem offiziellen Repository von Nous Research.

Schritt drei: Verbinde den Modellanbieter, den du nutzen willst. Claude ist eine Option, aber Hermes ist nicht an Anthropic gebunden.

Schritt vier: Hinterlege deinen Arbeitskontext und die Regeln für die erste Aufgabe.

Schritt fünf: Richte das dauerhafte Gedächtnis ein.

Schritt sechs: Füge die Skills hinzu, die der Agent für seine Aufgaben braucht.

Schritt sieben: Verbinde die benötigten Werkzeuge oder MCP-Server.

Schritt acht: Wähle einen Kommunikationskanal wie Telegram oder Slack.

Schritt neun: Begrenze die Tool-Rechte und lege fest, was du vor der Ausführung freigeben musst.

Eine eigene Oberfläche aus Claude Design wäre ein zusätzliches Projekt. Sie gehört nicht als fertige Funktion zu Hermes Agent.

Wenn du den offiziellen Repo-Link, meinen geprüften Neun-Schritte-Plan und die Wochenend-Checkliste haben willst, kommentiere SYSTEM und ich schicke dir alles zu.

**Aufnahme:** Schritte eins bis drei, vier bis sechs und sieben bis neun als drei getrennte Takes aufnehmen. Das schafft saubere Stellen für Cutaways.

## Reel 4: So arbeitet mein Signal Room

**Beleg-Reel:** [Claude als Social-Media-Manager](https://www.instagram.com/p/DblifbhBFhE/), 255.684 Plays, 6,55x Outlier

**Hook im Bild:** DIESES SYSTEM PLANT MEINE REELS MIT MIR

**Sprechdauer:** etwa 41 bis 46 Sekunden

**Skript**

Ich habe meinen kompletten Content-Research-Prozess in einem KI-Betriebssystem verbunden.

Mein Signal Room sammelt die Reels der beobachteten Creator mit allen Kennzahlen dahinter.

Er erkennt, welche Videos deutlich besser laufen als die normale Reichweite des Accounts. Danach zieht er die Transkripte, findet wiederkehrende Hooks und ordnet die stärksten Formate.

Aus diesen Belegen entstehen neue Ideen und Skripte für meine Zielgruppe. Das Quell-Reel, die Kennzahlen und das Transkript bleiben bis zum fertigen Skript verknüpft.

Ich wähle die Idee aus und gebe jeden Schritt vor der Produktion frei.

Wenn du den kompletten Signal-Room-Workflow als Schritt-für-Schritt-Plan haben willst, kommentiere SIGNAL und ich schicke ihn dir zu.

**Aufnahme:** Beim ersten Satz direkt in die Linse schauen. Für Kennzahlen, Transkript und Skript jeweils eine kurze Sprechpause lassen. Dort kommen später echte UI-Ausschnitte hinein.

## Reel 5: Codex prüft Claude Code

**Beleg-Reel:** [Claude und ChatGPT im Team](https://www.instagram.com/p/DcWsLMPgOoM/), 189.439 Plays, 4,85x Outlier

**Hook im Bild:** OPENAI HAT CODEX IN CLAUDE CODE GEBRACHT

**Sprechdauer:** etwa 46 bis 52 Sekunden

**Skript**

OpenAI hat ein offizielles Codex-Plugin für Claude Code veröffentlicht.

Damit kannst du Codex direkt aus Claude Code heraus für eine Prüfung starten oder ihm eine konkrete Aufgabe übergeben.

In der Praxis baut Claude zuerst. Danach startest du `/codex:review`. Codex untersucht die Änderungen und meldet seine Findings zurück. Für eine härtere Gegenprüfung gibt es `/codex:adversarial-review`. Wenn Claude festhängt, kann `/codex:rescue` einen zweiten Ansatz liefern.

Das Plugin holt nicht automatisch alle ChatGPT-Modelle in Claude. Du startest jeden Review oder jede Delegation bewusst.

Du brauchst Claude Code, einen installierten Codex-Client und einen passenden OpenAI-Zugang.

Wenn du den offiziellen Repo-Link, die Installationsanleitung und meinen Build-und-Review-Ablauf haben willst, kommentiere TEAM und ich schicke dir alles zu.

**Aufnahme:** Nach den drei Slash-Commands jeweils kurz pausieren. Die Befehle werden später als Paper-Editorial-Karten eingeblendet.

## Aufnahmereihenfolge

1. `SYSTEM` zeigt die Bausteine eines konkreten Agenten-Frameworks.
2. `SIGNAL` zeigt deinen eigenen Beleg.
3. `TIER` bringt das stärkste visuelle Format.
4. `FINANZ` übersetzt das Konzept in einen Führungsprozess.
5. `TEAM` zeigt einen konkreten Build-und-Review-Ablauf.
